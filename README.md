# Shashank Chandra — Portfolio

Public source for the static portfolio and browser-only project demonstrations.

## Public repository boundary

This repository may contain:

- The portfolio website and public media used by it
- Static, browser-only project demonstrations
- GitHub Pages deployment configuration

This repository must not contain:

- Live CloudVeyra application or backend implementation
- Azure authentication, Resource Graph integration, tokens, credentials, tenant IDs, or subscription configuration
- Environment files, local editor/MCP configuration, generated Graphify output, or historical working copies

The production-oriented CloudVeyra implementation is maintained in a separate private project. The public CloudVeyra folder contains sample data and local simulations only.
